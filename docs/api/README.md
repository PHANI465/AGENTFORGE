# API Documentation

The **API Gateway** (`:8000`) is the only service meant to be called directly —
Agent Runtime, Eval Service, and Trace Collector are internal-only (see
[`docs/diagrams/architecture.md`](../diagrams/architecture.md) for the service
boundary). Full interactive docs are auto-generated by FastAPI:

| Service | Swagger UI | OpenAPI JSON |
|---|---|---|
| API Gateway (public) | http://localhost:8000/docs | http://localhost:8000/openapi.json |
| Agent Runtime (internal) | http://localhost:8001/docs | http://localhost:8001/openapi.json |
| Eval Service (internal) | http://localhost:8002/docs | http://localhost:8002/openapi.json |
| Trace Collector (internal) | http://localhost:8003/docs | http://localhost:8003/openapi.json |

Everything below is captured live against the API Gateway's `openapi.json` —
if it ever drifts from what `/docs` shows, trust `/docs`.

## Auth

Every `/api/v1/*` endpoint requires an `X-API-Key` header. Get a dev key from
the seed script:

```bash
uv run python scripts/seed.py
# prints: Dev API key (save this — it won't be shown again): afk_...
export AGENTFORGE_API_KEY=afk_...
```

The key is stored hashed (`api_keys.key_hash`) — see
[`docs/security.md`](../security.md) for the full auth model.

## Response envelope

Every response is wrapped consistently (per `CLAUDE.md`'s API design convention):

```json
// success
{"data": {...}, "meta": {"next_cursor": "..." }}

// error
{"error": {"code": "not_found", "message": "Agent abc-123 not found"}}
```

## Agents

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/api/v1/agents` | Create an agent |
| `GET` | `/api/v1/agents` | List agents (cursor-paginated) |
| `GET` | `/api/v1/agents/{agent_id}` | Get one agent |
| `PUT` | `/api/v1/agents/{agent_id}` | Update an agent |
| `DELETE` | `/api/v1/agents/{agent_id}` | Delete an agent |

```bash
curl -H "X-API-Key: $AGENTFORGE_API_KEY" \
  http://localhost:8000/api/v1/agents?limit=1
```

```json
{
  "data": [
    {
      "name": "demo-support-agent",
      "model": "gpt-4o-mini",
      "system_prompt": "You are a helpful customer support agent for AgentForge.",
      "tools": [
        {"name": "search_web", "description": "Search the web for up-to-date information", "parameters_schema": {"type": "object", "required": ["query"], "properties": {"query": {"type": "string"}}}},
        {"name": "get_weather", "description": "Get the current weather for a city", "parameters_schema": {"type": "object", "required": ["city"], "properties": {"city": {"type": "string"}}}}
      ],
      "safety_policy": {"rules": ["never share customer PII"], "on_violation": "block"},
      "status": "active"
    }
  ],
  "meta": {"next_cursor": "..."}
}
```

Create one:

```bash
curl -X POST -H "X-API-Key: $AGENTFORGE_API_KEY" -H "Content-Type: application/json" \
  http://localhost:8000/api/v1/agents \
  -d '{
    "name": "my-agent",
    "model": "gpt-4o-mini",
    "system_prompt": "Be concise.",
    "safety_policy": {"rules": ["never share customer PII"], "on_violation": "block"}
  }'
```

## Runs & Traces

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/api/v1/agents/{agent_id}/run` | Execute an agent (send it a message) |
| `GET` | `/api/v1/agents/{agent_id}/runs` | List past runs for an agent |
| `GET` | `/api/v1/runs/{run_id}/trace` | Full execution trace (spans + summary) |

```bash
curl -X POST -H "X-API-Key: $AGENTFORGE_API_KEY" -H "Content-Type: application/json" \
  http://localhost:8000/api/v1/agents/$AGENT_ID/run \
  -d '{"input": "What is the weather in San Francisco?"}'
```

```bash
curl -H "X-API-Key: $AGENTFORGE_API_KEY" \
  http://localhost:8000/api/v1/runs/$RUN_ID/trace
```

```json
{
  "data": {
    "run_id": "e5352393-...",
    "status": "completed",
    "spans": [
      {"step": 1, "type": "llm_call", "latency_ms": 820, "tokens_in": 42, "tokens_out": 18},
      {"step": 2, "type": "tool_call", "latency_ms": 140, "input": {"city": "San Francisco"}},
```

## Evaluations

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/api/v1/eval-suites` | Create a test suite |
| `GET` | `/api/v1/eval-suites` | List test suites |
| `GET` | `/api/v1/eval-suites/{suite_id}` | Get one suite |
| `POST` | `/api/v1/eval-suites/{suite_id}/run` | Run a suite against its agent |
| `GET` | `/api/v1/eval-suites/{suite_id}/runs` | List runs of a suite |
| `GET` | `/api/v1/eval-runs/{eval_run_id}` | Get one eval run's scored results |
| `GET` | `/api/v1/eval-runs/{eval_run_id}/compare/{other_run_id}` | Diff two eval runs (pass-rate/latency/cost deltas) |

```bash
curl -X POST -H "X-API-Key: $AGENTFORGE_API_KEY" -H "Content-Type: application/json" \
  http://localhost:8000/api/v1/eval-suites/$SUITE_ID/run
```

## API Keys

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/api/v1/api-keys` | List keys (never returns the raw secret, only metadata) |
| `POST` | `/api/v1/api-keys` | Generate a new key (raw value shown once) |

```bash
curl -X POST -H "X-API-Key: $AGENTFORGE_API_KEY" -H "Content-Type: application/json" \
  http://localhost:8000/api/v1/api-keys \
  -d '{"user_id": "dev-user", "provider": "openai"}'
```

## Errors

| HTTP status | `error.code` | When |
|---|---|---|
| 401 | `unauthorized` | Missing or invalid `X-API-Key` |
| 404 | `not_found` | Agent/run/suite doesn't exist |
| 409 | `conflict` | (reserved for future uniqueness constraints) |
| 422 | `validation_error` | Request body fails Pydantic validation |
| 429 | `budget_exceeded` | Agent's `daily_budget_usd` already spent today |
